# Smart Farm Solar Platform

A web-based solar energy monitoring and management platform.

## Project Overview

Smart Farm Solar Platform is designed to monitor solar farms, analyze renewable energy production, track grid contribution, and manage multiple user roles.

## User Roles

1. Government Authority
2. Farm Owner
3. Grid Operator

## Technologies

- HTML
- CSS
- JavaScript
- PHP
- MySQL Database

## Main Features

- Solar farm monitoring
- Energy generation analysis
- Grid contribution tracking
- Farm performance ranking
- Reward management
- Notification system
